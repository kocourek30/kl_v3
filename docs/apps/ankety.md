# `ankety`

Hodnocení jídel a měsíční volba menu.

## Účel

- sběr hodnocení jídel,
- měsíční anketa a varianty,
- hlasování a agregace výsledků,
- frontend pro uživatele i admin reporty.

## Modely

- `AnketniOtazka`
- `HodnoceniJidla`
- `OdpovedHodnoceni`
- `MesicniAnketa`
- `MesicniAnketaVarianta`
- `MesicniAnketaHlas`
