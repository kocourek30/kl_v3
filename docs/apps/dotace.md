# `dotace`

Evidence a výpočet dotací pro strávníky a skupiny.

## Účel

- nastavuje dotační politiku,
- přiřazuje dotace jídelníčkovým skupinám,
- drží skupinová provozní nastavení,
- počítá výši dotace pro konkrétní objednávky.

## Modely

- `DotacniPolitika`
- `DotaceProJidelniskouSkupinu`
- `SkupinoveNastaveni`
- `Dotace`
