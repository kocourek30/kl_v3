# `pokladna`

Pokladní a finanční modul.

## Účel

- správa pokladen,
- pokladní doklady a uzávěrky,
- hotovostní zůstatky,
- QR/IBAN/BIC údaje pro platby,
- pokladní přehledy.

## Modely

- `DPHSkupina`
- `PLUKategorie`
- `PLUPolozka`
- `Pokladna`
- `PokladniDoklad`
- `PokladniPolozka`
- `PokladniSmazanaPolozka`
- `PokladniUzaverka`
- `PokladnaTile`
