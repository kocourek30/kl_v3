# `vydej_frontend`

Terminálový frontend pro výdej jídel.

## Účel

- přehled objednávek pro obsluhu,
- kiosk a fullscreen režim,
- RFID scan workflow,
- ruční i automatické vydání objednávky,
- refresh dat z backendu.

## Hlavní URL

- `dashboard`
- `terminal`
- `kiosk`
- `issue_order`
- `issue_single_item`
- `refresh_data`
- `rfid_scan`
- `kiosk_login`

## Modely

- front-end používá výdejní modely z `vydej` a nastavení z `vydej_jidel`
