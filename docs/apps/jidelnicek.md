# `jidelnicek`

Hlavní objednávkový a jídelníčkový modul.

## Účel

- správa katalogu jídel,
- jídelníčky a položky menu,
- dashboard pro přihlášeného uživatele,
- tvorba a rušení objednávek,
- AJAX/partial endpointy pro frontend.

## Hlavní view

- `dashboard`
- `menu_item_partial`
- `my_orders_partial`
- `order_create_view`
- `order_delete_view`
- `user_balance_api`

## Modely

- `Alergen`
- `DruhJidla`
- `Jidlo`
- `Jidelnicek`
- `PolozkaJidelnicku`
- `MenuImportRun`
- `JidloPhotoProposal`

## Doplnění

V modulu je i několik management commandů pro import a seedování jídelníčků a fotek jídel.
