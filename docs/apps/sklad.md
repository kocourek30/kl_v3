# `sklad`

Skladová a recepturová vrstva systému.

## Účel

- evidence surovin, dodavatelů a šarží,
- příjemky, inventury, odpisy a uzávěrky,
- pohyby skladu,
- receptury a komponenty jídel,
- měsíční spotřební koš a normy.
